# Windows App Installer

Automated application installer for Windows using Batch Script and WinGet.

# Currently available for installation

- Google Chrome;
- WhatsApp;
- Opera;
- 7-Zip;
- VLC.

# Features

- Check which applications are already installed;
- Install applications using WinGet;
- Install multiple applications;
- Update installed applications;
- Interactive menu using Windows CMD.

# How to use

1. Download the `installer.bat` file.
2. Run the file as administrator.
3. Follow the instructions displayed by the installer.
